# -REESTAR-CSS-SECOND-PORTFOLIO

🍽️ Restaurant Website

A clean, modern, and fully responsive restaurant landing page built from scratch. This project showcases the restaurant's menu using semantic HTML structure and custom CSS styling.

✨ Features

• Modern Hero Section: Eye-catching  menu viewing.
• Interactive Menu: A neatly organized menu section featuring signature dishes, descriptions, and pricing.
• Fully Responsive: Optimized layouts for seamless viewing across smartphones, tablets, and desktop computers.

🛠️ Technologies Used

• HTML5: Semantic elements for accessible and structured web layout.
• CSS3: Custom styling featuring Flexbox/Grid layouts, custom font pairings, smooth transitions, and media queries for responsiveness.
